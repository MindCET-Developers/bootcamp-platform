כל מה שבוטקמפ צריך

מסיגנל מפגש חי ועד פידבק אנונימי — חוויית המשתתף המלאה באפליקציה אחת מתארחת עצמית.

בית עם סיגנל חי

ספירה לאחור לפתיחת האירוע, אינדיקציית מפגש חי, הצגת המפגש הבא, והכרזות עדיפות — הכל במסך בית מבוסס כרטיסים.

לו"ז רב-יומי

טאבים לכל יום אירוע. כל כרטיס מפגש מציג סוג (הרצאה / סדנה / פאנל / נטוורקינג / ביקור), שעה, מיקום ותמונות דוברים.

ספריית משתתפים

רשת ניתנת לחיפוש של משתתפים מאושרים. סינון לפי שם, סטארטאפ או תחום עניין. ניתן להפעיל/לכבות לכל אירוע בנפרד מה-CMS.

פרופיל מקומי על המכשיר

המשתתפים ממלאים פרופיל ישירות במכשירם — ללא הרשמה, ללא אימייל. הפרופיל נשמר ב-PostgreSQL לאחר אישור מנהל. טוקן עריכה שמור רק ב-localStorage.

פידבק אנונימי למפגשים

דירוג כוכבים + תגובה אופציונלית לכל מפגש. נשמר אנונימית ב-PostgreSQL. ניתן להפעיל לפי אירוע מה-CMS. נתוני פידבק גלויים רק למנהלים.

ממשק ניהול Payload CMS

CRUD מלא לאירועים, ימים, מפגשים, דוברים, משתתפים והכרזות. גרור-ושחרר לסידור, טיוטות/פרסום, היסטוריית גרסאות וניהול הרשאות לפי תפקיד.

ארכיטקטורה

איך הכל מתחבר

שרת Next.js אחד מטפל באפליקציית המשתתפים, ממשק ה-CMS, וכל ה-APIs. אין מיקרו-שירותים, אין תשתית נוספת.

התחלה

הרצה מקומית ב-3 שלבים

דורש Docker ו-pnpm. אין חשבונות בתשלום, אין API keys.

1. הפעלת מסד הנתונים

הרצת קונטיינר PostgreSQL 17 ברקע. הנתונים נשמרים גם לאחר docker compose down — רק -v מוחק אותם.

2. הפעלת שרת הפיתוח

Next.js עולה על localhost:3000. Payload פועל באותו פורט תחת /admin. Hot reload, ללא תהליך CMS נפרד.

3. טעינת נתוני דוגמה (אופציונלי)

ייבוא אירוע אחד, 3 ימים, 18 מפגשים, 10 דוברים ו-12 משתתפים מאב-הטיפוס ה-HTML. אידמפוטנטי — בטוח להריץ מספר פעמים.

bash 
# 1 — הפעלת מסד הנתונים
docker compose up -d postgres

# 2 — הפעלת שרת הפיתוח
pnpm dev

# 3 — טעינת תוכן לדוגמה (אופציונלי)
pnpm seed
